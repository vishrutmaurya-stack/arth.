# Arth AI — Grounded HDFC Mutual Fund Research Assistant

A retrieval-augmented (RAG) chatbot that answers factual questions about five indexed
HDFC Mutual Fund pages on Groww. Answers come **only** from the indexed pages, include
**one citation**, and carry a **last-updated** timestamp. It refuses investment advice,
performance comparisons, PII, and facts that are not in the corpus.

> **Facts-only. No investment advice.**

---

## What it does

```
question
  → PII guard
  → intent guard (advice / performance / empty)
  → MiniLM embedding + Chroma retrieval (cosine, k=4, min score 0.55)
  → Groq generation, grounded in retrieved chunks only
  → citation selected in code from chunk metadata (never generated by the model)
  → answer + one Groww link + last-updated line
```

The UI is a Streamlit app with an Arth AI neon-light shell: an initialization screen
showing the real indexed sources, then the chat interface. It uses the actual corpus
stats — **5 sources, 152 chunks**:

| Source | Chunks |
| --- | ---: |
| AMC overview — HDFC Mutual Fund | 9 |
| HDFC Large Cap Fund Direct Growth | 36 |
| HDFC Flexi Cap Direct Plan Growth | 36 |
| HDFC ELSS Tax Saver Fund Direct Plan Growth | 37 |
| HDFC Mid Cap Fund Direct Growth | 34 |

Embedding model: `sentence-transformers/all-MiniLM-L6-v2` (384-d, cosine).

## Quick start (Windows, PowerShell)

```powershell
# 1. Create and activate a virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Install dependencies
python -m pip install -r requirements.txt

# 3. Configure secrets
Copy-Item .env.example .env
#    Edit .env and set GROQ_API_KEY (and LLM_MODEL if needed)

# 4. Run the app
.\run.ps1
# or:
.\.venv\Scripts\streamlit.exe run app\serve.py
```

Open <http://localhost:8501>.

The committed `data/chunks/` and `data/embeddings/` are enough to start: on first run
the app rebuilds `chroma/` automatically. If it is missing, you can also run:

```powershell
.\.venv\Scripts\python.exe -m app.ingest --phase store
```

### Generic (macOS / Linux)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then edit it
streamlit run app/serve.py
```

### Run on your local network (LAN)

```powershell
.\run.ps1 -Lan
# or:
.\.venv\Scripts\streamlit.exe run app\serve.py --server.address 0.0.0.0 --server.port 8501
```

Then open `http://<your-lan-ip>:8501` from another device on the same network. Allow
port 8501 through Windows Firewall if prompted.

## Configuration

`.env` (never committed):

```dotenv
GROQ_API_KEY=gsk_...
LLM_MODEL=qwen/qwen3.8-27b
```

On Streamlit Community Cloud, add the same keys in **App settings → Secrets**:

```toml
GROQ_API_KEY = "gsk_..."
LLM_MODEL = "qwen/qwen3.8-27b"
```

The app bridges Streamlit secrets into environment variables before the pipeline runs.

Other files:

- `config.yaml` — sources, chunking, retrieval, LLM settings
- `.streamlit/config.toml` — light theme palette
- `Doc/` — PRD, architecture, implementation notes

## Data pipeline

All phases are idempotent and write JSON artifacts under `data/`:

```powershell
# full ingest (re-scrapes the five Groww pages)
.\.venv\Scripts\python.exe -m app.ingest --from-phase scrape

# or individual phases
.\.venv\Scripts\python.exe -m app.ingest --phase load
.\.venv\Scripts\python.exe -m app.ingest --phase chunk
.\.venv\Scripts\python.exe -m app.ingest --phase embed
.\.venv\Scripts\python.exe -m app.ingest --phase store
```

`data/raw/` and `data/traces/` are runtime artifacts and are git-ignored.
`data/chunks/`, `data/embeddings/`, and `data/loaded/` are committed so the app can
start without re-scraping.

### CLI query

```powershell
.\.venv\Scripts\python.exe -m app.ask "What is the exit load for HDFC Flexi Cap Fund Direct Plan Growth?"
```

### Tests

```powershell
.\.venv\Scripts\python.exe scripts\run_guardrail_tests.py
.\.venv\Scripts\python.exe scripts\test_retrieval.py
```

## Deployment

### ✅ Streamlit Community Cloud (recommended)

This app is a Streamlit app, so the official Streamlit host is the simplest option and
free for public apps.

1. Push this repository to GitHub (see below).
2. Go to <https://share.streamlit.io> and sign in with GitHub.
3. **Create app → Deploy a public app from GitHub**.
4. Repository: `vishrutmaurya-stack/arth.` (note the trailing dot) · Branch: `main`
   · Main file path: `app/serve.py`.
5. In **Advanced settings → Python version**, choose **3.12**.
6. In **Advanced settings → Secrets**, paste:
   ```toml
   GROQ_API_KEY = "gsk_..."
   LLM_MODEL = "qwen/qwen3.8-27b"
   ```
7. Deploy. The first boot rebuilds `chroma/` from the committed chunks and embeddings.

### ✅ Render

`render.yaml` is included. Create a **New → Blueprint** in Render, connect the repo,
and set `GROQ_API_KEY` when prompted. The start command binds to `$PORT` and `0.0.0.0`.

> Free Render instances sleep after inactivity and may be tight on RAM because the
> embedding model runs locally. If it restarts on first query, use a plan with more
> memory or Streamlit Community Cloud.

### ✅ Hugging Face Spaces

Create a **Streamlit** Space, push this repo to it, add `GROQ_API_KEY` and `LLM_MODEL`
as Space secrets, and set the app file to `app/serve.py`. Spaces has a generous free
RAM allowance, which suits the local embedding model.

### ❌ Vercel

Vercel is **not suitable for this app**. Streamlit needs a long-lived Python process and
a WebSocket connection per session; Vercel runs stateless serverless/static deployments.
Hosting here would require rewriting the UI as a separate frontend and the pipeline as
an HTTP API with external state. Use Streamlit Community Cloud, Render, or HF Spaces
instead — no Vercel token is needed.

### Local hosting

Use `.\run.ps1` for localhost or `.\run.ps1 -Lan` to expose it on your LAN.
